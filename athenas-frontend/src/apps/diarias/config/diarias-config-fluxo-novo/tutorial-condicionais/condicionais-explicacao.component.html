Como funcionam as Condicionais

Cada grupo de condicionais pode conter uma ou mais condicionais, mas dentro de um grupo, você só pode utilizar um tipo de operador: "E" ou "OU".

Entre diferentes grupos, você pode utilizar operadores diferentes. Isso permite criar combinações mais complexas.


Exemplo 1: Se você quiser criar a seguinte condição: Condicional 1 E Condicional 2 OU Condicional 3, você deve:

  1. Criar um grupo com Condicional 1 e Condicional 2, utilizando o operador "E" entre elas.
  2. Criar um segundo grupo contendo apenas a Condicional 3 e selecionar "OU" como o operador entre grupos.

Exemplo 2: Para a condição Condicional 1 OU Condicional 2 E Condicional 3, você:

  1. Criar um grupo com Condicional 1 e Condicional 2, utilizando o operador "OU" entre elas.
  2. Criar um segundo grupo com Condicional 3 e selecionar "E" como operador entre grupos.

Dessa forma, você consegue criar combinações flexíveis de condicionais.
